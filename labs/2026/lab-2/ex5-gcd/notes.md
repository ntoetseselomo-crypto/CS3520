# Exercise 5: Greatest Common Divisor

## Purpose

The program calculates the greatest common divisor (GCD) of two integers using Euclid's algorithm.

## Register Usage

* `a0`: First number and returned GCD.
* `a1`: Second number.
* `t0`: Remainder.
* `ra`: Return address.
* `sp`: Stack pointer.

## Challenges

Implementing Euclid's algorithm using a loop, the `rem` instruction, and a procedure.
