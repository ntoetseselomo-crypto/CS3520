# Exercise 2: Sum of the First N Integers

## Purpose

The program calculates and prints the sum of the first N positive integers.

## Register Usage

* `t0`: Address of N.
* `t1`: Value of N.
* `t2`: Loop counter.
* `t3`: Running sum.
* `a0`: Value to print.
* `a7`: System call number.

## Challenges

Implementing the loop using conditional branching and updating the running sum.
