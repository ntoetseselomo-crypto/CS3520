# Exercise 3: Count Even Numbers

## Purpose

The program counts and prints the number of even elements in an array.

## Register Usage

* `t0`: Base address of the array.
* `t1`: Number of elements.
* `t2`: Array index.
* `t3`: Count of even numbers.
* `t4`: Current element and bit-test result.
* `t5`: Address of the current element.
* `t6`: Address of n.
* `a0`: Value to print.
* `a7`: System call number.

## Challenges

Using array indexing and the `andi` instruction to determine whether an element is even.
